### UI UX Theme color

- The UI will have a clean and modern design with a focus on usability and simplicity.
- The color scheme will be based on a combination of neutral tones with accent colors to highlight important elements and actions.


- Ash Grey

- Terracotta Clay
    Hex #b26e63
    RGB (178, 110, 99)

- Golden Sand
    Hex #CEC075
    RGB (206, 192, 117)

the above colors will be used strategically throughout the UI to create a visually appealing and cohesive design. The neutral tones will provide a calm and professional backdrop, while the accent colors will draw attention to key features and actions, enhancing the overall user experience.

- The UI will include visual indicators for the moderator and players, as well as clear buttons for actions like revealing cards and resetting the game.
